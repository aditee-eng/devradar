# DevRadar 🛰️

> Your personal developer activity tracker — GitHub + LeetCode in one place, with an AI-generated weekly digest.

---

## What it does

DevRadar pulls your real activity from GitHub and LeetCode every week, stores snapshots over time so you can track progress, and generates a personalized AI digest that reads like a smart friend summing up your week — not a corporate newsletter.

---

## Features

- **GitHub tracking** — commits, PRs opened, active repos this week
- **LeetCode tracking** — problems solved by difficulty, current streak, active days
- **Weekly snapshots** — stored in SQLite so you can see how you've improved over time
- **AI weekly digest** — generated by LLaMA 3.3 70B, specific to your actual stats
- **Automated scheduler** — runs every week automatically, no manual triggering
- **Flask dashboard** — clean web UI showing your stats and digest in one place

---

## Why I built this

As a CS student preparing for internships, I wanted one place to track my actual coding progress across platforms — not scattered across GitHub profile pages and LeetCode stats tabs. DevRadar aggregates everything and tells me honestly how my week went.

---

## Tech stack

- **Backend** — Python, Flask
- **Data sources** — GitHub REST API, LeetCode GraphQL API
- **Database** — SQLite (weekly snapshots)
- **AI** — Groq API (LLaMA 3.3 70B)
- **Scheduler** — APScheduler
- **Deployment** — Render

## Setup

1. Clone the repo
```bash
   git clone https://github.com/aditee-eng/devradar.git
   cd devradar
```

2. Create a virtual environment
```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
```

3. Create a `.env` file
GITHUB_USERNAME=your_github_username
GITHUB_TOKEN=your_github_token
GROQ_API_KEY=your_groq_api_key
LEETCODE_USERNAME=your_leetcode_username

4. Capture your first snapshot
```bash
   python database.py
```

5. Generate your first digest
```bash
   python digest.py
```

6. Run the dashboard
```bash
   python app.py
```

## Get API keys

- GitHub token — github.com → Settings → Developer Settings → Personal Access Tokens → public_repo scope
- Groq API key — [console.groq.com](https://console.groq.com)
- LeetCode — no API key needed, just your public username
